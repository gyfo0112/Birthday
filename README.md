# 🎂 Birthday

친구 **정예준**에게 링크로 보내는 모바일 전용 인터랙티브 생일축하 웹페이지.

## 목적 / 타겟
- 받는 사람: 정예준 (폰으로 확인)
- 생일: 10월 16일
- 분위기: 유쾌하고 장난스럽게, 마지막엔 진심 한 스푼
- **모바일 우선**: 세로 화면 기준 설계, 터치 인터랙션 중심

## 화면 흐름
1. **인트로**: "예준아, 생일이 찾아왔어요 🎉" + 시작 버튼 (탭해야 효과음/음악 재생 가능)
2. **케이크**: 케이크 + 촛불. 탭하거나 마이크로 후~ 불어서 촛불 끄기
3. **축하 연출**: 촛불이 꺼지면 컨페티 + 생일 노래(선택)
4. **편지**: 봉투를 탭해서 열면 축하 메시지
5. **엔딩**: "다시 보기" 버튼

> 추억 갤러리는 제외.

## 편지 메시지
> 예준아 생일축하한다! 가지고 싶은거 있으면 얘기해라! 오늘도 화이팅하고!

## 기능
| 우선순위 | 기능 |
|---|---|
| 필수 | 촛불 끄기, 컨페티, 편지 열기, 모바일 반응형 |
| 권장 | 이름·메시지를 `src/config.js` 한 곳에서 수정, 배경음악 on/off |
| 선택 | 마이크 입김 감지 |

## 기술 스택
- React + Vite
- CSS 애니메이션 + `canvas-confetti`
- 배포: GitHub Pages 또는 Vercel

## 모바일 고려사항
- 뷰포트 `100dvh` 사용, 주소창 변화 대응
- 터치 영역 최소 44px
- iOS 자동재생 제한 → 시작 버튼 탭 후 오디오 재생
- 마이크 권한은 HTTPS에서만 동작, 거부 시 탭으로 대체

## 단계별 계획
1. 프로젝트 세팅
2. 인트로 + 케이크/촛불 화면
3. 컨페티 + 편지
4. 모바일 실기기 점검 + 배포
